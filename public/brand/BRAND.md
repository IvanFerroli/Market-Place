## Visual Rules (quick)
- Primary accent: **Acid Yellow** `#FFE600`
- Suggested “silver” for logo on dark: `#DEE2E8`
- Backgrounds: very dark, bluish blacks.

Typography suggestion:
- Headings / brand: **Space Grotesk** (or **Sora**)
- UI: **Inter**
- Optional dev accent (labels/tags): **JetBrains Mono**

## Usage Notes
- Prefer the **Mark (NC)** for tiny sizes (<= 48px).
- Avoid using the **Hero (3D)** logo in tight UI areas — it loses clarity.
- Keep generous clear-space: at least **0.5×** the mark height around the logo.
